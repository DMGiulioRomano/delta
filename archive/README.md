# archive/

Materiale storico non piu' nella pipeline attiva ma conservato per consultazione.

## Contenuto

### `delta-engine/`

Motore Csound autonomo basato su transizione di stati in spazio parametrico multidimensionale. Sviluppato nel periodo "before Gamma". Include orchestra Csound (`orc/`), UDO (`udos/`), MACROS, tests, e script di analisi (memoria, armonia, spaziale). Vedi `delta-engine/README.md` per dettagli concettuali.

Resta invocabile stand-alone via il suo Makefile interno (`cd archive/delta-engine && make`).
